PROVA LOCALE
1. Aprire il file .html nel browser.
2. Scegliere ITINERARI > KITCHEN > BENVENUTO > ATLANTE > TAPPA 01 oppure aggiungere #tappa-01 alla fine del percorso del file nella barra indirizzi.
3. Spuntare la conferma di lettura.
4. Scegliere un primo gesto nella Stanza delle scelte, leggere il feedback, scegliere una prospettiva e concludere l'attività.
5. Creare due tessere libere (terza facoltativa), collocarle scegliendo una delle tre posizioni, riconsiderarle, e selezionare CONCLUDI L'ATTIVITÀ.
6. Ricaricare e verificare la consultazione in sola lettura delle tessere concluse.
Nota: aprendo in file:// l'agenda può risultare non disponibile perché il file originale richiede il JSON esterno agenda.json tramite fetch. In hosting corretto la disponibilità dipende dal file agenda.json servito dal sito; questa integrazione NON interviene sull'agenda.
